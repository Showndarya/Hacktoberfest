# Ayushi Jaiswal — Developer Portfolio

An original, responsive portfolio website made with HTML and CSS. No framework or build process is required.

## Preview locally
Open `index.html` in your browser. Google Fonts load when internet access is available; system fonts are used as a fallback.

## Add your profile photo
1. Create/use a photo cropped vertically or square.
2. Rename it to `profile.jpg`.
3. Put it in the `assets` folder, next to this README and `index.html`.
4. The portfolio will show the photo automatically. If the photo is missing, it shows an initials placeholder.

## Publish on GitHub Pages
1. Create a public repository named `ayushi25jaiswal.github.io` (or choose another repository name).
2. Upload `index.html`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment to complete. For the profile repository above, the URL will be `https://ayushi25jaiswal.github.io/`.

## Before going live
- Verify that your LinkedIn, LeetCode and project repository links point to the correct profiles.
- Optionally add a resume PDF to the repository and link it from the hero section.
- Check that you are comfortable publishing your email and education details publicly.
